# 测试与验收

## 1. 静态检查

```powershell
python -m compileall -q pictone cli.py id_photo_bg_changer.py
git diff --check
```

## 2. 图片验收

使用单人正面、复杂背景、深色头发、轻微倾斜以及 JPEG、PNG、WEBP 格式图片分别检查：

1. 图片能否正常打开。
2. 头发、耳朵和肩线是否保留。
3. 边缘是否存在白边、黑边或背景残留。
4. 蓝、红、白底是否均匀。
5. 一寸和二寸尺寸是否正确。
6. 自动构图后头顶留白和人脸比例是否合理。
7. 透明 PNG 是否包含 alpha 通道。
8. JPEG 是否可以被常用图片软件打开。

## 3. EXE 验收

在没有 Python 环境的 Windows 目录中启动 `证件照换底色.exe`，验证窗口、图标、模型加载、背景换色、规格调整、质量检查、保存、批量处理和打印排版。

问题记录应包含系统版本、入口、输入格式和尺寸、参数、完整错误信息、预期结果和实际结果。不要上传敏感原图。
