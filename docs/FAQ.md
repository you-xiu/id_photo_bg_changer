# 常见问题

## 1. EXE 提示缺少 tkinter

构建 EXE 的 Python 可能没有 Tkinter，或运行的是旧成品。先检查：

```powershell
python -c "import tkinter; print(tkinter.TkVersion)"
```

确认命令成功后，再按 [Windows 打包与发布](BUILD.md) 重新构建。

## 2. 没有检测到人脸怎么办？

人脸过小、遮挡、侧脸角度较大、光线过暗或图片模糊都可能导致检测失败。普通抠图仍可能完成，但自动构图和部分质量检查会缺少人脸结果。建议使用清晰、单人、正面图片。

## 3. 抠图边缘有白边怎么办？

查看透明抠图预览，调整背景容差、边缘净化和边缘羽化；桌面版还可以使用局部蒙版修复的删除、保留和柔化功能。

## 4. 输出尺寸是多少？

一寸为 `295 × 413`，二寸为 `413 × 579`，小一寸为 `260 × 378`，小二寸为 `390 × 567`。具体提交要求以使用单位规范为准。

## 5. 图片会上传到互联网吗？

默认不会。桌面版和命令行工具都在本机处理图片，不主动调用在线图片处理接口。

## 6. 如何提交问题？

请提供版本、系统、复现步骤和错误信息，先阅读根目录 `SECURITY.md`。不要在公开 Issue 中上传身份证件或其他敏感图片。
